# 06. Outreach and keeping replies

**When:** connection notes can go now (no link is needed); the follow-up message contains the app link, so send it only **after the app is public (14 Nov 09:00 PKT or later)** as `docs/OUTREACH.md` says. Check this timing with the team lead if in doubt. **Time:** 1 h plus waiting.

## What it is
A few targeted messages to Rescue 1122 district officers, PDMA Punjab, agriculture extension officers and researchers, asking whether the tool would help their work.

## Why it matters
Impact is the weakest score (3/5 in `docs/GRADE.md`: "No user has seen it"). One real reply, quoted with written consent, is rated +1.

## State at 1 Nov
Per the chat, Aiza sent 3 LinkedIn connection notes and Kissa planned 3 more (LinkedIn limits free accounts). Whether any accepted is not recorded in the repo.

## Steps
1. Open `docs/OUTREACH.md`. Use the English or Urdu connection note (≤300 characters), replacing `{role}`.
2. When someone accepts and the app is public, send the follow-up message and replace `{URL}` with the real link.
3. If they reply usefully, send the **consent wording** (section 3): options 1 (name and role), 2 (anonymous), 3 (no). Quote only with a written yes, and show them the exact text first.
4. Save the reply and consent as screenshots in a **private folder outside git**.
5. Tell Claude the quote (and the consent option) so it can add it to the project page; or paste into `docs/SUBMISSION.md`'s template via the AI.

## Rules (from OUTREACH.md)
No claimed endorsements; do not message private individuals in bulk; do not share the MAP_KEY or data links, only the public app URL.

## Common problems
- **LinkedIn note limit:** shorten; Urdu counts every letter.
- **No replies:** normal. The project does not depend on this; skip it if time runs out.
